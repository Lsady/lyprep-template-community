# LY Prep Template Community

## 快速查找

- [上传和转换记录](records/README.md)：按公开昵称、模版名、轨道数和时间查找，点击记录查看原始 PTXT 和转换结果。
- [社区模版](community/README.md)：查看用户主动发布的模版及介绍。新发布目录和文件名含社区昵称、模版名及唯一编号。

此仓库由 LY Prep 官网和自动转换任务维护。用户在官网提交 Pro Tools PTXT 后，
转换结果会自动出现在 `results/<job-id>/`。

请勿在 GitHub 网页中手动改动 `submissions/` 与 `results/`，否则摘要校验会失败。
