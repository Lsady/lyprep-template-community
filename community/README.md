# LY Prep 社区模版

用户在官网主动发布的模版存放在这里。上传转换记录可在[转换记录索引](../records/README.md)查找。

- [官网社区模版列表](https://lyprep.pages.dev/community.html)
- [社区数据索引](index.json)

新发布的目录和文件名会包含公开社区昵称和模版名称，例如：

```text
community/templates/小明--摇滚混音模版--唯一编号/
  小明--摇滚混音模版.lytemplate
  小明--摇滚混音模版.ptxt
  README.md
```

打开模版目录中的 README 即可查看作者填写的描述、轨道数和发布时间。唯一编号保留用于区分同名记录；登录邮箱不会作为公开文件名。

`.lytemplate` 是可下载的压缩模版文件，介绍请看 README。现有模版、原始 PTXT 和转换结果的下载路径保持不变。
